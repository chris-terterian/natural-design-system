# Natural Design System: working notes

- **Read `DESIGN.md` and `GOVERNANCE.md` first.** Follow the change tiers; add or update the entry in `governance/components.json` (new components start as Beta with known gaps in `notes`); log non-obvious calls in `DECISIONS.md`; add a `CHANGELOG.md` entry; refresh the Figma snapshot after any Figma or token change (`npm run figma:snapshot-script -- variables-1|variables-2|structure`, run each via the Figma MCP, save the results, `npm run figma:snapshot-save`), and run `npm run check` before asking to push.
- A pre-commit hook runs validate_file (blocks hardcoded values, broken naming, placeholder link text). Fix findings with tokens; never use --no-verify. Inline `validate-ignore <rule>: <reason>` only for real exceptions.
- Story UI (D-020) is local-only: never publish its workspace, never commit src/stories/generated, never touch .env keys. It learns from story-ui-considerations.md and story-ui-docs/ (generated by npm run tokens). After `story-ui update`, re-sync the lock file with npm 11.19 and re-check the typecheck.
- Dependencies: CI is pinned to Node 24.21.0 / npm 11.19.0. Regenerate the lock file with `npx npm@11.19.0 install`, never the local npm; `npm run check:install` proves it (D-018).
- `DESIGN.md` is the brand, voice, foundations, component and pattern brief; its front matter lists every token (value, alias, CSS variable) and is regenerated by `npm run tokens`. Keep §6 specs and §10 roadmap current; version history lives in `CHANGELOG.md`.

- Repo is the source of truth; Figma file "Natural Design System" (key `84MjZXozBoKCvf9lwIU5pu`) mirrors it via the figma-console MCP (Desktop Bridge).
- Change flow: edit code/tokens → verify in Storybook (port 6007) → update Figma (variables via `npm run figma:sync-script` output in `figma_execute`; component changes by hand + screenshot) → **ask the user before committing/pushing** to GitHub (`main`).
- Keep `tokens/figma-variables.json` names identical to Figma variable names. Figma variable names cannot contain `.` (use `1-5`, not `1.5`).
- Every component story: title `Components/<Figma component name>`, `parameters: figma(FIGMA_NODES.x)`, plus an `AllVariants` story laid out like the Figma grid (State columns, variant rows, labelled).
- Accessibility bar: WCAG 2.2 AA. Text ≥4.5:1, UI boundaries/focus ≥3:1, targets ≥24px, states never conveyed by colour alone. Disabled text is intentionally below 4.5:1 (WCAG-exempt).
- Figma pages: Buttons, Input Fields, Radio Buttons, Product Cards, Tags (Badge 2:171), Logo (Logo 153:822), Navigation Menu (section 59:42), Toggles (Toggle 67:360), Product Rows (Product Row 73:210), Typography (formerly Text; section 76:5; text styles Heading/*, Paragraph/*, Caption). Governance (80:5) and Proposals (80:6) pages follow Cover. Still empty: Images, Modal Form.
- Typography collection has Desktop/Mobile modes. Set a frame's mode in Figma; in code, mobile applies <768px or via data-nds-mode. Use Heading/Text components for all content copy; never hand-set sizes.
- The figma-console Desktop Bridge drops often. The official Figma MCP (`use_figma`, load the figma-use skill first) edits the same file without the plugin; prefer it when the bridge is down.
- Shared pieces are their own components and nested as exposed instances (Button in ProductCard CTA, WishlistButton, Badge). Don't hand-build a sub-element inside another component.
