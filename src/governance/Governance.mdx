# Governance

How the Natural Design System changes, and how you know what's safe to use. The full policy lives in
[`GOVERNANCE.md`](https://github.com/chris-terterian/natural-design-system/blob/main/GOVERNANCE.md); the reasoning behind
decisions lives in [`DECISIONS.md`](https://github.com/chris-terterian/natural-design-system/blob/main/DECISIONS.md).

This page is generated from `governance/components.json` and `governance/a11y-exceptions.json`, the same files the
blocking checks read, so it can't drift from what's enforced. Figma ↔ code parity is checked against
`governance/figma-snapshot.json`, exported from the live Figma file.
